# Advanced CSS

## Description
This project focuses on advanced styling techniques using CSS3. It covers establishing global CSS variables, custom typography, advanced layout mechanics using floats and grid systems, responsive utilities, card components, pseudo-classes, pseudo-elements, custom transitions, animations, and vendor prefixing.
