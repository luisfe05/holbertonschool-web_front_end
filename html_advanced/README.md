# HTML Advanced

## Description
This project covers the foundational principles of structuring web pages using semantic HTML5 elements, establishing correct document skeletons, hierarchy, and embedding multimedia without CSS styling.

## Tasks

| Task | Description | File |
| :--- | :--- | :--- |

| **1. Structure your webpage** | Added head and body tags inside html element. | [`1-index.html`](./1-index.html) |
| **2. The head...** | Configured charset, viewport, title, description meta, and favicon link tags. | [`2-index.html`](./2-index.html) |
